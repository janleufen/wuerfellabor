ICH:
Was ist mit "Kopiere die Web-App-Konfiguration aus den Projekteinstellungen in `firebase-config.js`." gemeint?

KI:
Damit ist der **Firebase-Einstellungsblock für eine Web-App** gemeint. Deine `firebase-config.js` enthält gerade noch Platzhalter wie `YOUR_API_KEY`; die ersetzt du durch die Werte aus deinem Firebase-Projekt.

1. Öffne dein Projekt in der [Firebase Console](https://console.firebase.google.com/).
2. Klicke auf das Zahnrad neben „Projektübersicht“ und öffne **Projekteinstellungen**.
3. Unter **Allgemein > Ihre Apps** registrierst du eine Web-App über das Web-Symbol `</>`, falls dort noch keine aufgeführt ist.
4. Firebase zeigt dir eine Konfiguration mit Feldern wie `apiKey`, `authDomain`, `projectId` und `appId`. Übertrage die Werte in die gleichnamigen Felder in `firebase-config.js`.
5. `databaseURL` findest du in den Einstellungen deiner **Realtime Database**. Achte darauf, genau diese URL einzutragen.

Zum Beispiel sieht die Datei danach ungefähr so aus:

```js
export const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "mein-projekt.firebaseapp.com",
  databaseURL: "https://mein-projekt-default-rtdb.europe-west1.firebasedatabase.app",
  projectId: "mein-projekt",
  appId: "1:123456789:web:abc123",
};
```

Die Werte unterscheiden sich bei jedem Firebase-Projekt. Die Web-Konfiguration ist für die Verwendung im Browser gedacht und kein Passwort. Teile aber keine privaten Service-Account-Schlüssel oder Zugangsdaten.

**Die App auf GitHub Pages veröffentlichen**

1. Erstelle auf GitHub ein Repository. Für kostenlose GitHub-Pages-Nutzung ist ein öffentliches Repository der unkomplizierteste Weg.
2. Lade die Dateien ins oberste Verzeichnis des Repositorys hoch: `index.html`, `app.js`, `styles.css`, `firebase-config.js`, `database.rules.json` und optional `README.md`. Das geht über **Add file → Upload files**.
3. Öffne im Repository **Settings → Pages**. Wähle bei **Build and deployment** die Option **Deploy from a branch**, dann den Branch `main` und den Ordner `/(root)`. Klicke **Save**.
4. GitHub zeigt dir dort nach der Veröffentlichung die Website-Adresse an. Sie sieht ungefähr so aus: `https://DEIN-NAME.github.io/REPOSITORY-NAME/`.
5. Damit Firebase Anmeldungen von der veröffentlichten App akzeptiert, füge in der Firebase Console unter **Authentication → Settings → Authorized domains** die Domain `DEIN-NAME.github.io` hinzu. Ohne `https://` und ohne den Repository-Pfad.

Danach öffnest du die GitHub-Pages-Adresse, startest eine Runde und testest den angezeigten Teilnahmelink am besten zusätzlich in einem zweiten Browser oder auf einem anderen Gerät. Die Firebase-Web-Konfiguration darf im Repository liegen; private Service-Account-Schlüssel gehören dort nicht hinein.
